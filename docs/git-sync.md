# Diagnostic report Git synchronization

Git sync is disabled by default. The Reports page can preview two proposed artifacts from an existing persisted guided-test report. Preview does not write files or stage changes. *Keep local* closes the preview and leaves the report in ReWeird's database.

Configure a trusted local backend with `REWEIRD_GIT_REPO` set to the exact root of the intended project worktree and `REWEIRD_GIT_SYNC_ENABLED=true` to offer the *Approve commit* action. The backend only accepts commit requests from loopback clients; each request also requires explicit approval. It writes new `.reweird/diagnostics/test-<id>.json` and `.reweird/reports/test-<id>.md` paths, refuses existing targets or symlinked parent directories, and commits only those two files. Unrelated index or working-tree changes are not included. The commit uses the repository's configured Git author and a `ReWeird: add diagnostic report …` message; it never impersonates another team member.

Push is separately guarded by `REWEIRD_AUTO_PUSH_REPORTS=true` **and** the explicit *Approve commit & push* button. It uses a normal, non-forced push to `origin` on the current branch. A concurrent remote update causes Git to reject the push; no force push or source-code rewriting is attempted. `REWEIRD_AUTO_COMMIT_REPORTS` and `REWEIRD_AUTO_PUSH_REPORTS` default to false and do not trigger unattended jobs in this release. The latter flag only enables the manually approved push path. These flags are reserved for a future scheduled mode with a separate approval design.

Generated reports are sanitized before preview. If sanitization redacted a known secret, if the generated artifacts match credential patterns, or if a configured secret environment variable's value appears in them, Git sync blocks the commit and reports why. It does not silently stage a redacted artifact. No uploaded source code or `.env` file is included. The scanner is defense in depth, not a guarantee against all secret formats; review the preview before approval. Report JSON and Markdown are each capped at 1 MiB.

If Git, the repository, author identity, or remote is unavailable, the preview or commit reports the issue. A failed push may leave an approved local commit; it is never silently retried. The Git integration does not modify project source files and is distinct from the human development commits made to the ReWeird repository.
